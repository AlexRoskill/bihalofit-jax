Tutorials
=========

Full worked examples, including multiple cosmologies, multiple redshifts, and
automatic differentiation:

- :download:`BiHalofit tutorial (3D matter bispectrum) <../notebooks/tutorials/bihalofit_jax_tutorial.ipynb>`
- :download:`Projected bispectrum tutorial (B_kappa, per-leg tracers) <../notebooks/tutorials/projected_bihalofit_tutorial.ipynb>`
- :download:`Aperture mass statistics tutorial (Map3) <../notebooks/tutorials/aperture_statistics_tutorial.ipynb>`
- :download:`Skew spectra tutorial <../notebooks/tutorials/skew_spectra_tutorial.ipynb>`

They follow the pipeline in order: the 3D bispectrum, its Limber projection, and
the two summary statistics built on that projection.

Download and open with ``jupyter notebook`` to run interactively.
